# Contributing to ChillGroup

ChillGroup is an open-source project and contributions of all kinds are welcome — code, documentation, translations, bug reports or just spreading the word.

## Ways to contribute

### Report bugs and suggest features

Open an issue on the GitHub repository describing:
- What you expected to happen.
- What actually happened.
- Steps to reproduce (if it is a bug).

### Improve documentation

The technical specification lives inside `definitions/` and is synced into this site automatically. If you spot an error or want to add a section, edit the relevant Markdown file and open a pull request.

### Translate pages

The detailed reference is currently written in Catalan. If you would like to translate pages into English (or any other language), check the `docs-site/docs/en/reference/` folder and open a PR with the translated file.

### Contribute code

1. Fork the repository on GitHub.
2. Create a feature branch: `git checkout -b feat/my-feature`.
3. Make your changes following the conventions in [Development](/en/reference/DEVELOPMENT).
4. Run the test suite (see [Testing](/ca/reference/TESTING)).
5. Open a pull request describing what you changed and why.

## Financial support

If you find ChillGroup useful and want to support its development, you can do so through the **Sponsor** button on the GitHub repository page. Funds help cover infrastructure costs, audits and developer time.

## Code of conduct

Be respectful. Harassment, discrimination or toxic behaviour of any kind will not be tolerated.

## Questions?

Open a GitHub Discussion or reach out through the contact details in the repository README.
