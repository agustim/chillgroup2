# Com contribuir a ChillGroup

ChillGroup és un projecte open source i les contribucions de tot tipus són benvingudes — codi, documentació, traduccions, informes d'errors o simplement difondre el projecte.

## Maneres de contribuir

### Informar d'errors i suggerir millores

Obre una issue al repositori GitHub descrivint:
- Què esperaves que passés.
- Què ha passat realment.
- Passos per reproduir-ho (si és un error).

### Millorar la documentació

L'especificació tècnica viu dins de `definitions/` i es sincronitza automàticament amb aquest portal. Si detectes un error o vols afegir una secció, edita el fitxer Markdown corresponent i obre una pull request.

### Traduir pàgines

La referència detallada és en català. Si vols traduir pàgines a l'anglès (o qualsevol altra llengua), revisa la carpeta `docs-site/docs/en/reference/` i obre una PR amb el fitxer traduït.

### Contribuir codi

1. Fes un fork del repositori a GitHub.
2. Crea una branca: `git checkout -b feat/la-meva-funcio`.
3. Fes els canvis seguint les convencions de [Development](/ca/reference/DEVELOPMENT).
4. Executa la suite de tests (veure [Testing](/ca/reference/TESTING)).
5. Obre una pull request descrivint els canvis i la motivació.

## Suport econòmic

Si trobes ChillGroup útil i vols donar suport al seu desenvolupament, pots fer-ho a través del botó **Sponsor** de la pàgina del repositori GitHub. Els fons ajuden a cobrir costos d'infraestructura, auditories i temps de desenvolupament.

## Codi de conducta

Sigues respectuós. L'assetjament, la discriminació o el comportament tòxic de cap mena no seran tolerats.

## Preguntes?

Obre una GitHub Discussion o contacta a través dels detalls del README del repositori.
